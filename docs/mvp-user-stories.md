# MVP User Stories for Marketing Agency Dashboard

## Client Experience
1. As a client admin, I can log in and see only my company's campaigns so I can trust data privacy.
2. As a client admin, I can view campaign KPIs over time so I can evaluate ROI.
3. As a client admin, I can see upcoming milestones and blockers so I know delivery status.
4. As a client admin, I can purchase add-on services via checkout so I can scale campaigns quickly.
5. As a client member, I can comment on updates so my team can collaborate with the agency.

## Agency Experience
1. As an account manager, I can update campaign progress so clients always see current status.
2. As an agency admin, I can create/edit services and pricing so the marketplace stays accurate.
3. As an agency admin, I can view purchase and subscription history so finance ops are centralized.

## Acceptance Criteria (MVP)
- Users authenticate and are authorized by role.
- Clients can view only tenant-scoped data.
- KPI cards and trend chart render from stored daily snapshots.
- Service checkout creates an order record and redirects to payment success/cancel flows.
- Order history is visible to client admins and agency admins.
